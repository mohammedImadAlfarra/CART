# Dataset — HTTP Params Dataset (real, public)

This folder holds the **real, recognised public dataset** used to train the
malicious-request classifier. It is **not** generated by this project.

## Source & licence
| | |
|---|---|
| **Name** | HTTP Params Dataset (`HttpParamsDataset`) |
| **Author** | Morzeux |
| **Source** | https://github.com/Morzeux/HttpParamsDataset |
| **Raw CSV** | https://raw.githubusercontent.com/Morzeux/HttpParamsDataset/master/payload_full.csv |
| **Licence** | MIT |
| **Size** | 31,067 labelled HTTP parameter values |

**How the dataset was built (by its author):**
- **Benign values** come from the **HTTP DATASET CSIC 2010** (Information Security Institute, CSIC — Spanish National Research Council).
- **SQL-injection** samples generated with `sqlmap`.
- **XSS** samples generated with `XSSYA`.
- **Command-injection / path-traversal** samples from `Vega Scanner` and `FuzzDB`.

> Citation: Morzeux, *HttpParamsDataset*, GitHub. Benign payloads derived from
> Giménez et al., *HTTP DATASET CSIC 2010*, CSIC.

## Folder layout
```
dataset/
  raw/
    http_params_dataset.csv   # the dataset exactly as downloaded (do not edit)
    SOURCE.txt                # provenance, licence, citation
  processed/
    features.csv              # numeric features extracted from each payload (generated)
  README.md                   # this file
```
`processed/features.csv` is regenerated from `raw/` by `ml/dataset.py`; it is
safe to delete (it will be rebuilt).

## Columns (raw)
| column | meaning |
|--------|---------|
| `payload` | the HTTP parameter value (string) |
| `length` | character length of the payload |
| `attack_type` | `norm`, `sqli`, `xss`, `cmdi`, or `path-traversal` |
| `label` | `norm` (benign) or `anom` (malicious) |

Label counts: **norm 19,304 · anom 11,763**.

## How it's used
1. `ml/dataset.py` turns each payload into **18 numeric features** (length, special-character
   counts, quotes, SQL/XSS/command keywords, traversal patterns, entropy, ...) and writes
   `processed/features.csv`.
2. `ml/dataset.py` → `clean()` removes duplicates **before** the train/test split
   (data-leakage check): 31,067 raw rows → **15,914** clean rows
   (34 contradictory rows + 15,119 duplicate feature vectors removed).
3. `ml/eda.py` describes the clean data (class balance, mean/median/mode/std of 6 key features, box plots).
4. `ml/train.py` compares Logistic Regression, SVM and Random Forest
   (GridSearchCV + 5-fold cross-validation, Accuracy / Precision / Recall / F1 / ROC-AUC).

If the raw file is missing and the network is unavailable, `ml/dataset.py`
falls back to a tiny bundled sample so the pipeline still runs — the output then
clearly says the sample was used, not the full dataset.
